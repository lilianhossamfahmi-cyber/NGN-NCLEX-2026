# Golden Clinical Data Schema (V3)

This schema defines the **Single Source of Truth** for patient data across ALL NGN item types (Case Studies, Bow Ties, Trends, Standalones).

> **Rule:** Every JSON generated by the Golden Prompts MUST adhere to this structure. This allows the `StudentPreviewModal` to consistently render the "Patient Info", "Vitals", "Labs", "Orders", and "Nurses Notes" tabs.

## Root Structure
```json
{
  "type": "item-type",
  "content": {
    "metadata": { ... },
    "patient": { ... },       // <--- REQUIRED
    "vitals": [ ... ],        // <--- REQUIRED (Array)
    "labs": [ ... ],          // <--- REQUIRED (Array)
    "orders": [ ... ],        // <--- REQUIRED (Array)
    "nursesNotes": [ ... ],   // <--- REQUIRED (Array)
    "rationale": { ... },
    "structure": { ... }      // <--- Item-specific fields (options, text, etc.)
  }
}
```

## Field Definitions

### 1. Patient Object (`content.patient`)
```json
"patient": {
  "name": "Initials or Name",
  "age": 45,                // Integer
  "sex": "Male" | "Female", 
  "weightKg": 70,           // Integer
  "allergies": "NKDA | ...",
  "codeStatus": "Full Code | DNR",
  "history": ["PMH 1", "PMH 2"],
  "homeMeds": [{ "name": "Drug", "dose": "...", "route": "...", "frequency": "..." }]
}
```

### 2. Vitals Array (`content.vitals`)
Must include all 7 fields for proper display.
```json
"vitals": [
  {
    "time": "0800",        // Strings "HHmm" or "HH:mm"
    "tempF": "98.6",       // String
    "hr": 80,              // Integer
    "rr": 18,              // Integer
    "bp": "120/80",        // String
    "o2": "98",            // String
    "o2_device": "RA",     // Room Air, 2L NC, etc.
    "pain": 0              // Integer 0-10
  }
]
```

### 3. Orders Array (`content.orders`)
```json
"orders": [
  {
    "order": "Name of Order / Drug",
    "orderedBy": "Dr. Name",
    "time": "0800",
    "status": "Active" | "Completed" | "Discontinued"
  }
]
```

### 4. Labs Array (`content.labs`)
```json
"labs": [
  {
    "test": "Glucose",
    "value": "110",
    "ref": "70-110",
    "flag": "H" | "L" | "N" | ""
  }
]
```

### 5. Nurses Notes / History (`content.nursesNotes`)
Always an array of entries.
```json
"nursesNotes": [
  {
    "time": "0800",
    "author": "RN Name",
    "entry": "SBAR formatted note..."
  }
]
```
