# NGN Question Stem & Options Standards (v3.2)

> **ACTIVE SOURCE OF TRUTH**
> Effective Date: 2026-01-14

This document defines the quality standards for the **Question Stem** and **Answer Options** to ensure high-fidelity NCLEX simulation.

---

## 1. The Question Stem
The stem must be clear, concise, and clinically situated.

### ✅ Structure
1.  **The Scenario (Context)**: Briefly sets the scene (e.g., "A client with heart failure...").
2.  **The Event (Problem)**: What is happening now? (e.g., "...suddenly develops dyspnea.").
3.  **The Query (Question)**: What must the nurse do? (e.g., "Which action should the nurse take first?").

### 🚫 Forbidden Patterns
*   **No Negatives**: Avoid "Which action should the nurse NOT take?" (Exception: Safety focus).
*   **No Fluff**: Remove irrelevant biographical data unless it is a distractor.
*   **No "All of the following except"**.

### ✨ Gold Standard Examples
*   **Better**: "The nurse cares for a client with COPD. Which finding warrants immediate intervention?"
*   **Worse**: "A 55-year-old male client with a history of COPD is admitted. The nurse checks him. Which of the following is bad?"

---

## 2. Answer Options
Distractors must be plausible and homogenous.

### ✅ Standards
*   **Homogeneity**: All options should be similar in length and grammatical structure.
*   **Plausibility**: Distractors should be based on common misconceptions or "close" clinical alternatives.
*   **Parallelism**: If the answer is an assessment, all options should be assessments. If intervention, all interventions.
*   **Count**:
    *   **Single Response**: Exactly 4 options.
    *   **Multiple Response**: 5-6 options.

### 🚫 Forbidden Patterns
*   **No "All of the above"** or "None of the above".
*   **No Outliers**: Avoid one option being significantly longer/shorter than others.
*   **No Absolutes**: Avoid "Always", "Never", "Must" in distractors (test-wise students eliminate these).

---

## 3. Formatting
*   **Ids**: Use "o1", "o2", etc.
*   **Text**: Sentence case. No trailing periods unless full sentences.
