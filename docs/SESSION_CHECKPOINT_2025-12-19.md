# Session Checkpoint - 2025-12-19

## 🚀 Summary of Changes
This file documents the major updates and fixes applied to the **Master NGN Generator** project during this session.

### 1. 🛠️ Renderer Improvements

#### **Highlight Renderer (`HighlightRenderer.tsx`, `ItemRenderer.tsx`)**
- **Fix:** Enabled **Fuzzy Matching** for correctness detection. The renderer now normalizes text (removes punctuation, ignores case) to match User selections with Config answers.
- **Fix:** Enabled **Rationale Display**. Previously, Highlight questions suppressed the bottom "Rationale & Educational Key" section. This block was removed, and rationales now appear for "Option Analysis".
- **Feature:** Added **Global Rationale** support. If `content.rationale` is present, it displays a "Clinical Summary" at the top of the rationale section.
- **Debug:** Added an on-screen **Debug Panel** (visible after submit) to inspect the raw `config` and `highlightItems` state.

#### **Ordered Response Renderer (`OrderedResponseRenderer.tsx`)**
- **UI Improvement:** Moved the "✔ Correct Position" / "✘ Should be step X" feedback **outside** the draggable item card. This prevents text overlap and improves visual clarity.
- **Styling:** Draggable cards now have a cleaner look with side-by-side validation messages.

#### **Citation Styling (`ItemRenderer.tsx`)**
- **Feature:** References in rationale text (formatted as `[1]`, `[2]`) are now automatically detected and rendered as **superscript** numbers (e.g., ¹, ²) with reduced opacity, improving readability.

### 6. 🧠 AI Robustness & Randomization (New Update)
**Timestamp:** 2025-12-19 19:33

#### **AI Compatibility (`src/config/promptTemplates.ts`)**
- **Issue:** Search-based AIs (like Perplexity) were attempting to search the web or output citation links, breaking strict JSON parsing.
- **Fix:** Added "CRITICAL FOR PERPLEXITY / SEARCH-BASED AI" header to **ALL 9** prompt types/templates.
  - **DISABLE SEARCHING**: Explicit instruction to use internal knowledge only.
  - **RAW JSON ONLY**: Enforced strictly.
  - **NO CITATION LINKS**: Explicitly banned markdown links for citations (using plain `[1]` instead).

#### **Answer Randomization (`src/components/item-types/ItemRenderer.tsx`)**
- **Issue:** AI-generated content frequently placed the correct answer as the first option ("Option A bias").
- **Fix:** Implemented an **Automatic Frontend Shuffling** mechanism in `normalizeConfig`.
- **Scope:** Now randomizes options for:
  - **Single Response (Multiple Choice)**
  - **SATA (Multiple Response)**
  - **Bow-Tie**: Shuffles Actions, Conditions, and Parameter pools independently.
  - **Matrix**: Shuffles row order.
  - **Cloze**: Shuffles dropdown options.
  - **Trend**: Shuffles answer choices.
- **Benefit:** Eliminates AI order bias without needing detailed prompt engineering or regeneration.
