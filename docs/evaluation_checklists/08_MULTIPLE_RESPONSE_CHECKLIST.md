# MULTIPLE RESPONSE (SATA) ZERO-ERROR CHECKLIST

**Objective:** Validate Select All That Apply items.

## 1. Option Logic (The N-Rule)
- [ ] **Minimum Correct**: At least one option is correct.
- [ ] **Maximum Correct**: Can be ALL options.
- [ ] **Count**: 5-7 total options provided. Less than 5 is weak; more than 8 is cognitively overloading.

## 2. Plausibility Check
- [ ] **Homogeneity**: All options are grammatically similar (e.g., all interventions, all symptoms).
- [ ] **Distractor Quality**: Distractors are not "silly". (e.g. "Call the Ghostbusters" is invalid).

## 3. Answer Key
- [ ] **Boolean Flag**: Every option has an `isCorrect` boolean property.
- [ ] **Validation**: The explanation explicitly addresses why EACH option is T/F.
