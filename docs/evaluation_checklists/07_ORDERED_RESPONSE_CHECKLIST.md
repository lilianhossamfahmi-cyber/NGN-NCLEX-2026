# ORDERED RESPONSE ZERO-ERROR CHECKLIST

**Objective:** Validate Sequencing/Drag-Link items.

## 1. Sequence Logic
- [ ] **Uncontestable Order**: The correct order is widely accepted in nursing literature (e.g., standard procedural guidelines).
- [ ] **No Simultaneous Steps**: Avoid steps that happen at the same time (e.g., "Assess pulse" and "Assess breathing" might be simultaneous in a rapid assessment). Steps must be distinct.

## 2. Option Integrity
- [ ] **Count**: 4-6 draggable items.
- [ ] **Distractors**: (Optional) Some schemas allow items that are NOT part of the sequence. If so, they must be clearly incorrect. Most NGN Ordered Response uses "All items must be ordered".

## 3. Answer Key
- [ ] **Array Match**: The `correctOrder` array contains the IDs of the options in the correct sequence.
- [ ] **Completeness**: All required option IDs are present in the key.
